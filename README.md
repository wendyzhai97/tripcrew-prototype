# TripCrew Prototype

A lightweight mobile-style web prototype for a collaborative group trip planner.

The prototype explores a Mexico City friend trip where the app adapts around:

- traveler profiles
- adaptive itinerary changes
- split-up and regroup planning
- budget-aware decisions
- cash/card/currency settlement concepts
- low-power check-in ideas

## Run Locally

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Prototype Notes

This is a static clickable prototype. It does not include a backend, real maps, location sharing, payments, or live settlement logic yet.
